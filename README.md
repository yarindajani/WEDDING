# הזמנת חתונה — מוכנה ל־GitHub Pages

הזמנה עצמאית בעברית, ללא התקנה וללא תהליך build. ההזמנה הותאמה לירין ואנה באולם AVENUE, השרון 1, קריית שדה התעופה. התאריך עודכן ל־22.10.2026 (השנה הונחה כאוקטובר הקרוב); השעות עדיין להמחשה; מספר WhatsApp טרם הוגדר. מעטפה לבנה עם פפיון סאטן ועיצוב פרחוני בצבעי מים בהשראת Bloom. שמות באנגלית על המעטפה ובתוך ההזמנה: YARIN & ANNA.

## התאמה בלי לערוך קוד

פתחו את editor.html. מלאו שמות, תאריך, שעות, אולם וכתובת. לשימוש באישורי הגעה, מלאו מספר WhatsApp בינלאומי ללא מקפים (לדוגמה: 972501234567). הסירו את סימון תצוגת הדוגמה כשכל הפרטים נכונים.

לחצו ״הורדת index.html״. זה הקובץ המעודכן שצריך להעלות. השינויים בתצוגה בלבד אינם נשמרים לקובץ המקורי. העורך אינו מערכת ניהול עם שמירה בשרת.

אפשר להוסיף תמונה: שמרו קובץ בשם couple.jpg לצד index.html והזינו couple.jpg בשדה התמונה. העלו גם את התמונה למאגר. תמונה בקישור HTTPS נתמכת גם היא.

## העלאה ל־GitHub

1. צרו מאגר חדש ב־GitHub. במסלול GitHub Free השתמשו במאגר Public.
2. לחצו Add file → Upload files והעלו את index.html המעודכן לשורש המאגר (לא את קובץ ה־ZIP ולא תיקייה שבתוכה הקובץ). העלו גם את avenue.png המצורף — זו תמונת האולם. אם הוספתם תמונת זוג, העלו גם אותה.
3. היכנסו ל־Settings → Pages.
4. ב־Build and deployment בחרו Deploy from a branch, ענף main ותיקיית / (root), ואז Save.
5. לאחר סיום הפרסום יופיע הקישור בעמוד Pages. בדרך כלל המבנה הוא https://USERNAME.github.io/REPOSITORY/.

מדריך GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## מה כלול

- פתיחת מעטפה עם חותם ואנימציה.
- עברית מימין לשמאל, התאמה לנייד ותמיכה במקלדת ובהפחתת תנועה.
- פרטי האירוע, ספירה לאחור לפי שעון ישראל כולל שעון קיץ, תמונת זוג אופציונלית.
- ניווט ב־Google Maps והורדת אירוע ליומן.
- אישור הגעה, מספר משתתפים והערות בהודעת WhatsApp מוכנה. האורח חייב לשלוח אותה בעצמו.

אין בסיס נתונים, אין רשימת אורחים מרכזית ואין שמירה אוטומטית של תשובות. אם מספר WhatsApp לא הוגדר, מוצגת הודעה ולא נשלח דבר. קוד העורך ציבורי כמו יתר האתר, אבל מבקר אינו יכול לשנות את האתר המפורסם — רק להוריד עותק משלו. אין לכלול בקובץ סיסמאות או רשימות אורחים.

האתר עובד גם עם גופני מערכת. הגופנים המעוצבים נטענים מ־Google Fonts כשהאינטרנט זמין. פתיחת ניווט ו־WhatsApp דורשת חיבור לאינטרנט. האירוע ביומן מוגדר לחמש שעות החל מקבלת הפנים.
